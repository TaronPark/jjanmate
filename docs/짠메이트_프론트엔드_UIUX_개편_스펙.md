# 짠메이트 프론트엔드 UI/UX 개편 스펙 (v1.0)

> 작성일: 2026-07-26
> 목적: 투박한 MVP 프로토타입 UI를 당근마켓·인스타그램의 검증된 모바일 문법(하단 탭 바, FAB, 상대 시간, 미니멀 리액션)으로 개편해 사용성과 몰입감을 높인다. E2E QA/CBT(로드맵 5주차) 착수 전, 지금 UI로 QA를 돌리는 게 의미가 없다고 판단해 그 직전에 끼워넣는 폴리싱 스프린트.

## 1. 개요 및 범위

- 대상 화면: 메인 피드 및 상단/하단 네비게이션 구조
- 핵심 원칙:
  - 신규 의존성 추가 최소화(번들 크기 방어)
  - 기존 백엔드/DB/AI 파이프라인 로직 무변경 — UI 레이아웃과 표현만 개편

## 2. 레퍼런스 벤치마킹

- 당근마켓: FAB, 사람 냄새 나는 마이크로카피(상대 시간), 하단 탭 바 중심 네비게이션
- 인스타그램: 콘텐츠 우선 카드 레이아웃, low-friction 아이콘 리액션

## 3. 상세 개편 스펙

### ① 네비게이션 (GNB → 하단 탭 바)

- **하단 고정 탭 바 도입**
  - 노출 조건: 메인 피드 진입 이후에만 노출. 로그인·약관·온보딩·닉네임 설정 등 인증 전 화면에서는 숨김
  - 탭 구성(3개):
    1. `[홈]`: 현재 내가 속한 룸(`profiles.onboarding_niche`) 피드
    2. `[둘러보기]`: 다른 니치 룸 목록에서 원하는 룸으로 입장하는 단순 허브. 활동량 통계 등은 표기하지 않음 — 룸 상태 그대로를 열람하는 것이 목적
    3. `[마이페이지]`: 닉네임, 유효 스트릭(🔥), 내가 작성한 글 목록, 로그아웃 버튼
  - 비회원 예외: 비회원이 `마이페이지` 탭을 클릭하면 로그인 화면(`/login`)으로 유도
- **마이페이지 "내가 쓴 글 목록" 스펙**
  - `status='success'` 글뿐 아니라 `low_confidence`/`system_error` 글도 전체 포함
  - 미분류 글은 지금 피드와 동일하게 반투명 + 상태 배지로 노출(유저가 본인 글 상태를 인지할 수 있도록)

### ② FAB (플로팅 액션 버튼 — 글쓰기)

- 위치/형태: 우측 하단(하단 탭 바 바로 위) 고정, 둥근 펜 아이콘. 기존 상단 헤더의 글쓰기 버튼은 완전히 제거
- **니치 컨텍스트 유지 규칙** (기준은 "지금 보고 있는 화면"이지 "어느 탭에서 왔는지"가 아님):
  - 지금 보고 있는 화면이 특정 니치 룸(`/feed/[niche]`)이면: 그 룸을 그대로 유지해서 글쓰기로 이동. 홈 탭에서 들어온 룸이든, 둘러보기를 거쳐 들어간 다른 룸이든 동일하게 적용
  - 지금 보고 있는 화면이 룸이 아닌 화면(둘러보기 인덱스, 마이페이지)이면: 유저의 `profiles.onboarding_niche`로 폴백

### ③ 피드 카드 (타이포그래피 및 날짜 표기)

- **룸 타이틀**: `niches.ts`의 `roomName` 데이터 구조는 변경하지 않음. 모바일 화면에서 이질감 없이 떨어지도록 CSS(쉼표 기준 줄바꿈, word-break, 줄간격)만 보정
- **작성 시간**: 신규 라이브러리(date-fns/dayjs) 설치 없이, `lib/date.ts`에 상대시간 함수를 추가해 처리. 표기 단계는 "방금 전 → N분 전 → N시간 전 → 어제 → 그 이전은 날짜"

### ④ 리액션 (공감 칩 스타일링)

- 로직 무변경: 기존 낙관적 UI(`ReactionButtons.tsx`, 로컬 state 즉시 반영 → 실패 시 롤백)와 스키마(`cheer`/`me_too`)는 그대로 유지
- 스타일만 개편: 크고 각진 텍스트 버튼(`대단해요 5`) → 얇은 아웃라인 아이콘+카운트 칩(`👍 5`, `🙌 2`). 텍스트 라벨은 넣지 않음
- 클릭 시 배경색이 Primary 컬러로 채워지는 활성 토글은 기존 그대로 유지
