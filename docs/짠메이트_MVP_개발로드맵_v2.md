# 짠메이트 MVP 개발로드맵 v2 (레딧형 업보트 커뮤니티 재개발)

> 작성일: 2026-08-02
> 본 문서는 「짠메이트 MVP 기획서 v2」의 실행 계획입니다. 기존 니치/AI 태깅 기반 구현(1~5주차 완료분)을 재사용 가능한 부분(인증, 스토리지, 배포 인프라, UI 셸)과 폐기 대상(AI 파이프라인, 니치 피드, 스트릭, 매칭 프리뷰)으로 구분하고, 폐기 대상을 신규 설계로 교체합니다.

## 기존 자산 재사용/폐기 판정

**재사용**
- 인증: 카카오 OAuth 플로우, `profiles` 테이블의 계정 기본 구조
- 인프라: Vercel 배포, Supabase 프로젝트, 이미지 스토리지 버킷
- UI 셸: `BottomTabBar`, `FAB`(라우팅 대상만 변경), 페이지 레이아웃 골격, `getRelativeTimeKo`

**폐기**
- `lib/ai/classifyPost.ts`, `app/api/tags/route.ts`, `app/api/cron/retry/route.ts` (AI 태깅 파이프라인 전체)
- `lib/niches.ts`, `app/feed/[niche]/*`, `app/feed/[niche]/ReactionButtons.tsx` (니치 피드 + 2종 리액션)
- `lib/streak.ts` (스트릭)
- `app/preview/page.tsx` + `matching_previews` 테이블 (매칭 프리뷰)
- `app/api/cron/drip/route.ts`의 니치 기반 시드 드립 로직 (룸 기반으로 재작성 필요)

## 1단계: DB 마이그레이션 + 핵심 테이블

- `rooms`(6개 고정 시드), `post_flairs`(24개 고정 시드, 룸당 4개)
- `posts`(room_id, flair_id, title, body, author_status 등)
- `votes`(post_id | comment_id, user_id, value −1/0/+1, unique 제약)
- 기존 `reactions` 테이블 및 니치 컬럼 제거

## 2단계: 투표 + 핫스코어 엔진

- 업/다운보트 API, 낙관적 UI
- Raw Hot Score / Popular Hot Score 계산 로직 구현(γ=1.2 시간감쇠, W_room 0.5~2.0 캡, 콜드스타트 부스트, 최대 노출시간 컷오프)
- 정렬(최신/핫) 쿼리

## 3단계: 3축 피드 UI

- 홈 피드(룸 선택 + 정렬), 룸 상세 피드(플레어 필터), 둘러보기(6개 룸)
- 기존 `app/explore/page.tsx` 룸 기반으로 교체

## 4단계: 글쓰기 플로우

- 전체화면 글쓰기 모달, 룸/플레어 선택 → 컨텍스트별 3/2/1단계 입력
- 초안 자동저장(30초 간격, 24시간 만료, 유저당 1개)
- 이미지 4:5 캐러셀, 플레어별 동적 필드(예: 투표형 "한줄질문")

## 5단계: 댓글 시스템

- 1뎁스 스레드 댓글, 대댓글 1단계 제한
- 베스트 댓글 고정(+10 임계), 다운보트 접힘(−5 임계)

## 6단계: 유저 플레어 + 1클릭 작성자 상태

- 유저 플레어 자유입력(5자 제한) + 블랙리스트 검증(부분일치 + 정규화 정규식)
- 1클릭 작성자 상태(고정 4종) UI/로직

## 7단계: 북마크 + 마이페이지 재구성

- 북마크(다중 탭존)
- 마이페이지 4탭(게시글/댓글/북마크/보상명예) + 설정 드로어

## 8단계: 월간 배지/보상 배치

- 월간 스냅샷/리셋 배치 job (Vercel Hobby 크론 제약 검토 후 구현 방식 확정)
- 룸별 TOP3(왕관/별) + 전체 TOP3(글로우) 로직, 축하 UX

## 9단계: 문서/법률 정비

- 이용약관/개인정보처리방침: AI 처리위탁·국외이전 조항 삭제, 투표/댓글/유저플레어/모더레이션 관련 조항 검토·추가
- `docs/짠메이트_MVP_기획서.md`, `docs/짠메이트_MVP_개발로드맵(상세).md` 상단 대체 공지는 완료(2026-08-02)

## 10단계: QA + CBT 재준비

- 전체 플로우 회귀 테스트, `tsc --noEmit` / 빌드 검증
- 시드 데이터로 룸별 콘텐츠 밀도 확보 후 비공개 베타(CBT) 재개
